# Dice Racers browser playtest

Open https://edianibarrola.github.io/diceracer/ in portrait. Choose a racer and a Desert Cup event, then LET'S RACE. Each racer has independent upgrades and event progress. Complete races for shared coins and character mastery. Buy +2 movement upgrades in the garage; claim a glow trail at 50 mastery. Opening events have three racers. Clearing an event unlocks the next. Four dice each have Move, Attack and Guard controls; selective reroll is available once per move. Move adds the exact face value to distance. Attack denies twice the face value in movement and Guard blocks twice the face value in attack. Level upgrades add the displayed fixed movement bonus; opponents have fixed event strength. No persistent speed or hidden stat multipliers. Progress is saved locally to this browser/device. Matching dice assigned to one action earn immediate bonuses. Tap a charged ability to arm it and press Ready. The private Unity source is kept separately.

Gzip with Unity decompression fallback supports static Pages hosting. No source project, credentials or Unity Library files are included.
