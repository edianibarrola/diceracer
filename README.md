# Dice Racers browser playtest

Open https://edianibarrola.github.io/diceracer/ in portrait. Tap a racer, choose Cruise or Rival, then LET'S RACE. Four dice each have Move, Attack and Guard controls; selective reroll is available once per move. Move adds the exact face value to distance. Attack denies twice the face value in movement and Guard blocks twice the face value in attack. No persistent speed or hidden stat multipliers. Matching dice assigned to one action earn immediate bonuses. Tap a charged ability to arm it and press Ready. The private Unity source is kept separately.

Gzip with Unity decompression fallback supports static Pages hosting. No source project, credentials or Unity Library files are included.
