# Dice Racers browser playtest

Open https://edianibarrola.github.io/diceracer/ in portrait. Choose an unlocked stop on the Desert Cup map and tap RACE. Open Garage for upgrades and a swipeable racer roster. Each racer has independent upgrades and event progress. Orbit, Bolt and Spark can be earned with coins and clear goals; Nova, Rex and Pip remain available. Levels display from Level 1. Existing saves are preserved. Complete races for shared coins and character mastery. Buy +2 movement upgrades in the garage; claim a glow trail at 50 mastery. Opening events have three racers. Clearing an event unlocks the next. Four dice each have Move, Attack and Guard controls; selective reroll is available once per move. Move adds the exact face value to distance. Attack denies twice the face value in movement and Guard blocks twice the face value in attack. Level upgrades add the displayed fixed movement bonus; opponents have fixed event strength. No persistent speed or hidden stat multipliers. Progress is saved locally to this browser/device. Matching dice assigned to one action earn immediate bonuses. Tap a charged ability to arm it and press Ready. The private Unity source is kept separately.

Gzip with Unity decompression fallback supports static Pages hosting. No source project, credentials or Unity Library files are included.
